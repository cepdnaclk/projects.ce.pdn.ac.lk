This CO5420 project automates fabric defect detection to replace error-prone manual inspection using the AITEX database. Handling extreme image dimensions via patch-based processing, we benchmark GLCM/SVM models against CNNs for classification. Finally, we contrast supervised U-Net and unsupervised Autoencoders for precise defect localization.
