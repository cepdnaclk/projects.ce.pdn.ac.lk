OrthoSense is a low-cost, AI-powered wearable system for orthopedic rehabilitation monitoring. Using multimodal sensors, ESP32-S3, TinyML, and IoT, it tracks knee movement, pressure, temperature, and impact, detects hazardous movements, and enables remote rehabilitation monitoring through a web dashboard.
